Hanzi Quest v5 — RPG Learning System

Что внутри:
- глобальная модель знаний: значение, pinyin, иероглиф, аудирование, письмо, контекст;
- большой Босс урока с HP и 30 заданиями;
- магазин с редкими монетами и предметами;
- питомцы;
- Карта испытания, Испытание судьбы и Ключ испытания;
- специальные Боссы: Дракон знаний, Босс Забвения, Босс Тишины, Босс Каллиграф, Босс Смысла;
- 30 встроенных контекстных предложений для слов из примера пользователя;
- импорт TXT/CSV только после предварительного просмотра и подтверждения;
- PWA manifest + service worker для GitHub Pages / «На экран Домой».

Локальный запуск:
1) Windows: START_HANZI_QUEST.bat
2) macOS/Linux: START_HANZI_QUEST.command или START_HANZI_QUEST.sh
3) Браузер откроет http://127.0.0.1:8765/

GitHub Pages:
- загружай содержимое архива в корень репозитория, НЕ сам ZIP;
- index.html должен лежать в корне;
- Settings → Pages → Deploy from a branch → main → /(root).

Импорт:
- 汉字 pinyin русский перевод
- 汉字 | pinyin | перевод
- tab-separated / semicolon / CSV

Важно: примерный TXT пользователя НЕ встроен как словарь. Встроены только контекстные шаблоны предложений для 30 слов, чтобы функция предложений могла работать сразу после импорта соответствующих слов.
